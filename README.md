# 🛒 CommerceProject

콘솔 기반 커머스 플랫폼입니다.
상품, 카테고리, 장바구니, 고객 등급 등 여러 객체가 각자의 역할을 맡고 서로 협력하도록 **객체 지향 설계**를 적용했습니다.

<br>

## 📌 개발 환경

- Java 17 (Temurin 17)
- IntelliJ IDEA

<br>

## ▶️ 실행 방법

**IntelliJ**

1. 프로젝트를 열고 `src/commerce/Main.java`를 엽니다.
2. `main` 메서드 옆의 실행 버튼을 누르거나 `Shift + F10`(Mac: `Ctrl + R`)으로 실행합니다.

**터미널**

```bash
javac -encoding UTF-8 -d out src/commerce/*.java
java -cp out commerce.Main
```

> 관리자 모드 비밀번호: `admin123`

<br>

## ✨ 주요 기능

### 필수 기능

- **상품 조회**: 카테고리(전자제품 / 의류 / 식품)를 고르고, 상품을 선택해 상세 정보(가격, 설명, 재고)를 확인합니다.
- **캡슐화**: 모든 필드를 `private`으로 막고 Getter/Setter로만 접근합니다. 상품 목록은 읽기 전용 리스트로 반환합니다.

### 도전 기능

**Lv 1. 장바구니 및 주문**
- 상품을 장바구니에 담기 전에 재고를 확인합니다. 장바구니에 이미 담긴 수량까지 합쳐서 확인합니다.
- 장바구니에 상품이 있을 때만 `[ 주문 관리 ]` 메뉴(장바구니 확인 / 주문 취소)가 나타납니다.
- 주문을 확정하면 재고를 차감하고 장바구니를 비웁니다.

**Lv 2. 관리자 모드**
- 비밀번호 인증을 거치며, 3회 실패하면 메인 메뉴로 돌아갑니다.
- 상품 추가: 같은 카테고리 안에서 상품명이 중복되지 않도록 검증합니다.
- 상품 수정: 상품명으로 검색한 뒤 가격 / 설명 / 재고수량을 수정합니다.
- 상품 삭제: 삭제 전에 확인을 받고, 장바구니에 담긴 상품이면 장바구니에서도 제거합니다.
- 전체 상품 현황을 카테고리별로 출력합니다.

**Lv 3. Enum, 람다 & 스트림**
- `CustomerGrade` Enum으로 등급별 할인율(BRONZE 0% / SILVER 5% / GOLD 10% / PLATINUM 15%)을 관리하고, 주문할 때 할인을 적용합니다.
- 카테고리 안에서 가격대별 필터링(100만원 이하 / 초과)을 람다와 `stream().filter()`로 구현했습니다.
- 장바구니에서 상품명으로 상품을 제거하는 기능을 `stream().filter()`로 구현했습니다.

## 🧩 클래스 구조와 역할

```
src/commerce
├── Main.java            # 프로그램 시작점, 초기 상품·카테고리 데이터 생성
├── CommerceSystem.java  # 고객 흐름 제어 (메뉴 입력, 상품 조회, 장바구니, 주문)
├── AdminMode.java       # 관리자 흐름 제어 (인증, 상품 추가·수정·삭제, 현황)
├── Category.java        # 카테고리 이름과 상품 목록 관리 (추가·삭제·검색·필터링)
├── Product.java         # 상품 정보와 재고 관리 (가격·재고 검증, 재고 차감)
├── Cart.java            # 장바구니 항목 관리 (추가, 제거, 수량·총액 계산)
├── CartItem.java        # 장바구니에 담긴 상품 한 줄 (상품 + 수량)
├── Customer.java        # 고객 정보 (이름, 이메일, 등급)
└── CustomerGrade.java   # 고객 등급별 할인율 (Enum)
```

| 클래스 | 책임 |
| --- | --- |
| `CommerceSystem` | 고객이 쓰는 메뉴의 입력과 출력, 화면 흐름을 담당합니다. |
| `AdminMode` | 관리자 기능을 담당합니다. 고객 흐름과 분리해 CommerceSystem이 비대해지지 않도록 했습니다. |
| `Category` | 상품 목록을 직접 관리합니다. 상품 추가는 `addProduct()`로만 가능해서 중복 검증을 빠뜨릴 수 없습니다. |
| `Product` | 자기 상태(가격, 재고)를 스스로 검증하고, 재고 확인·차감을 담당합니다. |
| `Cart` / `CartItem` | 장바구니에 담긴 상품과 수량, 총액 계산을 담당합니다. |
| `CustomerGrade` | 등급별 할인율과 할인 금액 계산을 담당합니다. |

## ⚠️ 예외 처리

| 상황 | 처리 방식 |
| --- | --- |
| 숫자가 아닌 입력 | `NumberFormatException`을 잡아 안내 메시지를 출력합니다. |
| 메뉴에 없는 번호 입력 | 안내 메시지를 출력하고 메뉴로 돌아갑니다. |
| 재고보다 많이 담으려는 경우 | 장바구니 수량까지 합쳐 확인하고, 부족하면 경고합니다. |
| 빈 장바구니에서 주문 관리 메뉴 선택 | 예외를 던지고 `start()`에서 잡아 안내합니다. |
| 가격·재고에 음수 입력 | `Product`에서 `IllegalArgumentException`을 던집니다. |
| 같은 카테고리에 중복 상품명 | 추가하기 전에 검증해 막습니다. |
| 관리자 비밀번호 3회 실패 | 메인 메뉴로 돌아갑니다. |
| 주문 중 재고 부족 | 모든 상품의 재고를 먼저 확인해 일부만 차감되는 일을 막습니다. |
